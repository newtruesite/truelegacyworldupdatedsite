# Product images (HD)

- **k8.png** — Present. Leveluk K8 Kangen Water machine thumbnail is installed and used on country pages and the K8 product page.
- **emguarde.png** — Add your emGuarde HD image here (e.g. your standalone 8K/portrait PNG). Name it exactly `emguarde.png` so the country and EmGuarde product pages show the photo instead of the placeholder.

Paths used in the app:

- Country page product cards and K8 page: `/products/k8.png`
- Country page product cards and EmGuarde page: `/products/emguarde.png`

Use high-resolution PNGs (e.g. 800px+ width) for sharp display. If a file is missing, the site shows a styled placeholder (icon + product name) for that product.
